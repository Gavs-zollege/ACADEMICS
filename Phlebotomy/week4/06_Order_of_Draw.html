Order of Draw

Arrange the tubes from first draw to last using the arrows.

Correct venipuncture order of draw:
1. Blood cultures (Yellow) → 2. Light Blue (Coagulation) → 3. Red (Serum) → 4. Gold/Tiger top (SST) → 5. Light Green (Lithium Heparin) → 6. Dark Green (Sodium Heparin) → 7. Lavender (EDTA) → 8. Gray (Glucose)
